# 高频时序面试题集

四块的关系（先背这个）：

```text
微观结构描述世界
    → Hawkes 描述单子什么时候来
    → HJB 决定现在买/卖各报多远
    → C++ 决定报价能不能先到
    → 费率 + 队列模拟 决定扣完成本还剩没有
```

阶段 A 从 **OFI 回归** 开始，不要从 HJB 的方程开始。

## 必考

| 主题 | 一句话 | 典型问法 |
|---|---|---|
| 热路径 | 行情进到订单出：零分配、无锁、看 p99 | 一笔 tick 里你绝不会做什么 |
| p99 | 延迟是分布；均值好看、尾巴才是被抢先 | 为什么不报平均延迟 |
| 零分配 | 启动开缓冲，运行不再 `new` | 分配一次贵在哪 |
| 无锁环 | 收行情和策略用 SPSC，mutex 等的是 p99 | 为什么不用队列加锁 |
| 价差非零 | 对面可能更知情，价差是逆向选择保险 | 为什么买卖价不贴死 |
| 冲击 | 你买多少价格推多少（Kyle λ / 平方根） | 大单为什么不能按中间价成交 |
| OFI | 现在谁在主动吃档 | OFI 和「我这单为何成交」差在哪 |
| 两种成交 | 价格走到你 ≠ 被人专门吃 | 回测按中间价穿过就算成交，错在哪 |
| Hawkes | 底噪 + 过去每笔的余波，解释成簇 | 和泊松差在哪 |
| VPIN vs Hawkes | VPIN：这簇有多少知情；Hawkes：还会烧多久 | 两个都能量成交量扎堆吗 |
| HJB 两句 | 货多整张往下挪；怕风险/波动大则价差宽 | 做市模型到底在优化什么 |
| 控制状态 | 现在怎么做，取决于以后还能怎么办 | 库存、离收盘、只禁开，和 HJB 什么关系 |

## 进阶

| 主题 | 一句话 |
|---|---|
| 微观价格 | 加权中间价 / microprice，不是 last，也不是简单 mid |
| 队列位置 | FIFO 里你排第几，决定先被走到还是先被吃 |
| 价差拆开 | 库存成本 + 逆向选择 + 手续费，不是一个「α」 |
| 分支比 | Hawkes 余波积分 < 1 才稳定；≥1 会爆 |
| 标记点过程 | 量当 mark；大单余波更长，不是每笔一样 |
| 事件时间 | 簇内用事件钟；聚到 2h 和 VPIN 一样死 |
| 库存 vs 方向 | 做市可以没有方向 α；有信号是改保留价，不是另起炉灶 |
| Avellaneda–Stoikov | HJB 的一个可讲特解：保留价随库存偏，价差随 σ、γ 变宽 |
| P(成交) | 报得越近越容易成交，也越容易被知情单打 |
| 撤改 | 撤单/改价本身是事件，进 Hawkes，也吃交易所频率限制 |
| 回测接口 | 同一 `on_md` / `send`；差别只在时钟和撮合，见 sys 口条 |

## 压轴

| 主题 | 一句话 |
|---|---|
| 填单亏损 | 你的限价单成交，往往是信息对你不利的瞬间 |
| 不能 mark-to-mid | 高频 PnL 按中间价盯会虚；要用实际成交和队列 |
| 潜伏套利 vs 预测 | 快 2μs 吃过时盘口，不是「预测涨跌」 |
| 隐藏量 | 冰山/暗池让 OFI、队列估计偏；冲击会低估 |
| ACD vs Hawkes | ACD 管间隔；Hawkes 管强度被历史点激发 |
| 校准 | 短窗 Hawkes 过拟合簇；要分支比、半衰期、样本外强度 |

## C++ 热路径

**Q1. 「会写 C++」和热路径 C++ 差在哪？**  
口条：热路径是行情进到订单出的那一小段，必须又快又稳。不是 STL 熟、虚函数玩得转。启动把缓冲开好，运行不再分配；收发用环，谁也不等谁；数字看 p99 不看均值。

**Q2. 为什么零分配？`new` 一次有多贵？**  
口条：分配一次经常是几百纳秒，而且抖（锁堆、走系统）。p99 被几次分配钉死。对策：对象池、环形缓冲、定长 POD。研究脚本可以 `vector` 乱扩；`on_md` 里不行。

**Q3. 为什么无锁？mutex 不也能同步？**  
口条：锁的代价是等待。均值还能看，最倒霉的那几次（锁被日志/页错误/另一核拿走）就是 p99 炸、单子被抢。单产单消用 SPSC 环；多策略就多条环，别把 mutex 塞进 tick。细节见 `sys_interview` 01–04。

**Q4. 为什么看 p99 不看平均延迟？**  
口条：延迟是一条分布。均值 8μs、p99 80μs，被捡走的是尾巴那些单。和看 MaxDD 不看平均收益是同一套思维。见 `01_p99_vs_mean.py`。

**Q5. 热路径里日志、异常、虚函数为什么也不行？**  
口条：日志是 syscall 和锁；异常是冷路径表；虚调用打断预测、难内联。启动期可以；tick 里错误走状态机。

**Q6. 先到和算得对，哪个决定 PnL？**  
口条：做市/抢价，先到才有队列和价差。算得对但晚 50μs，边在费率里。中频股票相反：边在 PIT 和冲击，不在 2μs。先问战场。

## 微观结构

**Q7. 价差为什么不是零？**  
口条：对面可能比你知道得多。挂在最好价，成交往往是知情单来打你。价差是逆向选择保险，加上库存和手续费。不是「买卖双方懒得贴」。

**Q8. Kyle λ、平方根冲击分别说什么？**  
口条：你买多少，价格推多少。线性 Kyle：ΔP ≈ λQ，知情交易渗进价格。临时冲击常写成 |Q|^α（α≈0.5）对成交量。回测按中间价成交 = 假设 λ=0。见 `04_kyle.py`。

**Q9. OFI 是什么？阶段 A 为什么从它开始？**  
口条：买卖档量的增减，刻画谁在主动。可回归、可复现、有论文口径。它问「现在盘口被谁推」。见 `02_ofi.py`。

**Q10. OFI 和「我这单为什么成交」为什么不能混？**  
口条：OFI 是市场主动流。你的成交有两种：价格走到你的挂单（被动），或被人专门扫你（主动被选中）。混起来，回测会把「本该被逆向选择」算成「信号对了」。搞混后两种，回测会漂亮。

**Q11. 中间价穿过就算成交，错在哪？**  
口条：没队列、没量、没手续费、没撤单。价格扫过 mid 不保证你排在队头，更不保证对手还在。高频必须仿真簿记或至少：队列位置 + 可见量 + 费率。

**Q12. mid、microprice、last 怎么选？**  
口条：last 被一笔带偏。简单 mid 忽略档口量。microprice / 量权 mid 把两边量加权，更接近「下一笔可能成交的价」。信号用谁，成交也必须用同一套语义。

**Q13. 队列位置为什么比「我报了买一」更重要？**  
口条：FIFO 里你是队头还是队尾，决定先吃价差还是吃剩渣。同样买一，后排等价于更差的有效价。回测没有队列 = 默认你永远队头。

**Q14. 做市价差可以拆成哪几块？**  
口条：库存（货多了要减仓）+ 逆向选择（怕被知情打）+ 手续费/maker-taker + 延迟（你改价够不够快）。HJB 主要管前两块；C++ 管最后一块。

## Hawkes

**Q15. Hawkes 和泊松差在哪？**  
口条：泊松：强度常数，单子均匀到。市场成簇：一笔大单后面跟一串。Hawkes：λ(t)=μ + Σ 过去每笔的余波 φ(t−t_i)。不管涨跌，只管事件何时发生。见 `03_hawkes.py`。

**Q16. Hawkes 解释什么、不解释什么？**  
口条：解释成交量/波动扎堆，也能生成假订单流压模拟器。不解释方向（除非做成有标记、有买卖两个过程）。方向是微观结构 + 因子的事。

**Q17. VPIN 和 Hawkes 各问什么？**  
口条：VPIN：这簇里有多少知情（买卖不平衡）。Hawkes：这簇还会烧多久（强度还多高）。都能看扎堆；问题不同。聚到 2 小时 bar 上用，和 VPIN 一样会死——簇被平均掉了。

**Q18. 分支比是什么？为什么必须 < 1？**  
口条：一支事件平均还会生出几支后代，n=∫φ。n<1 过程稳定；n≥1 强度爆炸。面试会问「你校准出来的 n 是多少」：接近 1 很近真实，等于 1 要小心。

**Q19. 为什么大单和小单不能共用一个 φ？**  
口条：标记点过程：量（或主动性）当 mark，大单余波更强更长。无标记 = 每笔一样，簇形状假。

**Q20. Hawkes 和 ACD 怎么选？**  
口条：ACD 建模间隔（下一笔要等多久）。Hawkes 建模强度（现在有多热）。成簇、互激发（买激发买、买激发卖）用 Hawkes；只要久期用 ACD。都可以在事件时间上做。

**Q21. 短样本上校准 Hawkes 的坑？**  
口条：一上午一个大簇，φ 会拟合成「几乎不衰减」。要看样本外：下一段的强度曲线、分支比是否稳。不要在 2h 聚合数据上谈微观 Hawkes。

## HJB / 做市控制

**Q22. HJB 在做市里到底管什么？不管什么？**  
口条：不管方向预测。管「现在买/卖各报多远」。状态：库存、离收盘多久、（可选）短信号。动作：两边报价偏移。确定性叫动态规划；价格随机就叫 HJB。

**Q23. 必须留下的两句是什么？**  
口条：多头越多，整张报价往下挪（急着卖）。越怕风险、波动越大，价差报得越宽。见 `05_inventory_spread.py`。

**Q24. 为什么「现在怎么做取决于以后还能怎么办」？**  
口条：收盘前必须平、A 股有到期/只禁开、PCM 槽位有限：未来可行集小了，今天就要更急。这就是终端惩罚 + 状态约束。G0 只禁开、40 日到期，和做市库存是同一类控制，不是另一门课。

**Q25. 没有方向 α 能做市吗？**  
口条：能。边来自价差 − 逆向选择 − 库存风险 − 费。有短信号时，平移保留价（觉得要涨则卖价更硬、买价更积极），不是把 HJB 扔掉改成分类器。

**Q26. 报得近是不是更好？**  
口条：成交概率升，但被知情打的概率也升。HJB 的最优是在「成交强度」和「成交质量」之间折中，不是贴 mid。

**Q27. 为什么阶段 A 不要从 HJB 方程开始？**  
口条：方程漂亮，数据没对齐。先能复现 OFI、冲击、队列和费率，才知道控制的状态和成本是真的。否则是在错的世界上做最优。

## 我认为有必要补的

**Q28. 限价成交为什么常常是亏的？（压轴）**  
口条：你的买一被打掉，常常是有人比你更急着卖——信息对你不利。回测里「挂单成交 + 中间价立刻向你」是幻觉；真实是成交后 mid 常对你反方向走。这叫 adverse selection，用成交后短窗 mid 变化就能验。

**Q29. 高频能不能按中间价记盈亏？**  
口条：不能当主评估。mid 盯市把没成交的纸面波动算进去，又假设你能在 mid 平。要用实际成交、隔夜/收盘强制平、扣费。和 `python_interview` 10/22「看净不看 accuracy」同一句。

**Q30. 快 2μs 算预测吗？**  
口条：多半是潜伏套利：对方盘口还没更新。这是工程和共址，不是时序 α。面试要分开：预测涨跌 vs 先到。

**Q31. 事件时钟和日历时钟怎么用？**  
口条：强度、OFI、Hawkes 用事件/成交额钟（你已会 dollar bar）。风控、收盘、A 股时限用日历。混用会在安静时段造出假因子。

**Q32. 回放必须满足什么？**  
口条：同一套时间戳、同一 `on_md`，行情乱序和重传按实盘规则。Hawkes 生成的假流可以压系统，但不能替代带队列的历史回放。

**Q33. 手续费和 maker-taker 插在哪一层？**  
口条：微观给世界，HJB 给报价，C++ 给到达，**费率在最后一层把边吃掉**。很多「有 α」的 OFI 回归，扣完 taker 费是负的。先报未扣费再报净。

## 20 分钟口述稿（对着四块）

1. 微观：K 线是结果；价差、冲击、OFI、成交原因四问。  
2. Hawkes：泊松不会簇；λ=μ+余波；VPIN 问知情，Hawkes 问还烧多久。  
3. HJB：报多远，不报方向；货多往下、怕风险价差宽；约束像槽位和到期。  
4. C++：零分配、无锁、p99；先到才有后面的价差。  
5. 评估：队列 + 费率 + 成交后短窗，不看 mid 纸面和 accuracy。
