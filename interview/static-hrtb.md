# `'static` 和 HRTB（`for<'a>`）

对应：`cargo run --bin 17_static_hrtb`。

## `T: 'static`

**不是**「必须是全局常量 / 活到进程结束」。  
意思是：`T` **里面没有指向短寿命数据的引用**。`String` 拥有自己的数据，是 `'static`；`&local` 不是。

`spawn` 要 `'static`：任务可能比当前函数活得久，不能借调用者的栈。业务里比 HRTB 常见。

## HRTB 是什么

**HRTB = Higher-Ranked Trait Bounds**。写法 `for<'a> ...`，读作：对任意寿命 `'a` 都成立。

```rust
F: for<'a> Fn(&'a str) -> usize
```

约束的不是字符串要活多久，而是：**闭包每一次入参那条 `&str` 允许有多短——答案是多短都行。**  
主要就是为了：`apply` **自己栈上**刚造的 `local`，能把 `&local` 传给 `f`。

`Fn(&str)` 在这种位置通常是省略写法，和写出 `for<'a>` 一样。文件里写出来是为了让你看见。

## 语法为什么长这样

`for` = for all（∀）。`<'a>` 和 `fn foo<'a>` 一样，先引入寿命名字。

```text
for  <'a>   Fn(&'a str)
 │    │         └── 这一次传入的借用活多久
 │    └── 引入寿命变量
 └── 对每一个这样的 'a
```

| 写法 | `'a` 谁定 | 意思 |
|---|---|---|
| `fn apply<'a, F: Fn(&'a str)>` | 调用 `apply` 时定一次 | `f` 只要接得住**这一个**（往往偏长的）`'a` |
| `F: for<'a> Fn(&'a str)` | 每次 `f(...)` 自己定 | 栈上刚借出来的短引用也能传 |

没有 `for`，`'a` 挂在外层函数上，里面新建的 `local` 通常塞不进去。

## 什么时候会用到

日常业务几乎不手写。给「写接收闭包的 API」用的：自己造一段短命借用，再交给调用方的闭包。

量化：从行情缓冲切出 `&str`，回调只许当场读，不许存到下一根 tick。`for<'a>` 把「当场读、不许藏」写成类型。

闭包 `|s| s.len()` 不存 `s`，过 HRTB。  
`|s| { slot = Some(s); }` 把引用藏起来，只对某一种 `'a` 成立，HRTB 会拒。

口条：**`for<'a>` = 闭包能用「我函数里头刚借出来的那点栈上数据」，用完不能藏。**
